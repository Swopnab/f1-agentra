# Signalroom

A student-first, independent educational website concept about agentic research,
risk awareness, and human judgment. Static HTML, CSS, and JavaScript; no build
step, dependencies, server integrations, or financial services.

## Demo, not trading results

Every company, symbol, chart, score, evidence packet, and decision in the demo is
fictional. Nothing represents actual account information, stock prices, trades,
returns, backtesting, or validated forecasts. Scores are not win probabilities.
The demo intentionally includes incomplete and adverse scenarios.

This is not financial, immigration, or tax advice. The F-1 audience reference does
not establish eligibility for any activity. There are no legal-safety guarantees,
broker affiliations, testimonials, or investment performance claims.

## Privacy boundaries

- No private workspace files, brokerage snapshots, research journals, or credentials.
- No account linking, order submission, sign-in, forms, analytics, cookies, browser
  storage, live feeds, or background requests.
- Interactions use only fixed in-memory fixtures and reset on reload.
- External resource links are visitor-initiated and use no-referrer protections.
- Hosting services may process normal request logs under their own policies.
- Public repository ownership, commit metadata, and the Pages URL are public.

## Local preview

From this repository, run `python3 -m http.server 8786 --bind 127.0.0.1` and open
`http://127.0.0.1:8786/`. This serves the standalone demo, not a trading system.

## GitHub Pages

Publish the `main` branch from the repository root under Settings → Pages.
Relative assets work with a repository-scoped Pages URL. `.nojekyll` keeps the
site buildless. Do not add private project files to this repository.

## Accessibility

Responsive layouts, semantic landmarks, keyboard-focus indicators, a skip link,
native disclosure controls, pressed-state scenario buttons, live decision text,
and reduced-motion support are included. No third-party fonts or images load.
